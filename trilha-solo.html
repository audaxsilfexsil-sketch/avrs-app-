Mapa de uma jornada pela Metodologia AVR-S

“A mente é o solo. As escolhas são as sementes. Os hábitos são o cultivo. A vida é a colheita.”

Como usar este guia: marque com ✓ cada item que completar e escreva nos campos. Só avance de estação quando o “Sinal de Passagem” for verdadeiro para você.

Suas respostas ficam salvas automaticamente neste aparelho e neste navegador. Se trocar de aparelho ou limpar o navegador, elas se perdem. Para guardar uma cópia, use o botão Imprimir / salvar em PDF.
